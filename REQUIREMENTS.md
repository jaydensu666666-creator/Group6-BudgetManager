# Walking Skeleton - User Requirements

## Main Feature: Recording Expenses

UR-1: As a user, I want to record my expenses
so that I can track my spending.

UR-2: As a user, I want to enter an expense
amount so that the system can calculate
how much I spent.

UR-3: As a user, I want to see my remaining
budget after recording an expense.

UR-4: As a user, I want the system to reject
invalid expense amounts.
